# ✈️ Travel Planner

เว็บวางแผนการท่องเที่ยว — จัดตารางกิจกรรมรายวัน คุมงบประมาณแยกหมวด เตรียมของด้วย
Checklist และดูเส้นทาง/ระยะทางบนแผนที่ ออกแบบให้ใช้บนมือถือเป็นหลัก

## ตั้งค่า Supabase (ต้องทำก่อนใช้งาน)

ระบบล็อกอินและฐานข้อมูลใช้ Supabase — ต้องตั้ง 2 อย่างนี้ก่อน

### 1. สร้างตารางในฐานข้อมูล

เปิด Supabase Dashboard → **SQL Editor** → วางไฟล์ [`supabase/schema.sql`](supabase/schema.sql)
ทั้งไฟล์ → กด Run (รันซ้ำได้ ไม่พัง)

สคริปต์นี้สร้างตาราง `trip_states`, bucket `trip-photos` สำหรับเก็บรูป
และตั้งสิทธิ์ 2 ชั้นซึ่งต้องมีทั้งคู่

| ชั้น | ทำอะไร | ถ้าขาด |
| --- | --- | --- |
| `GRANT` | role `authenticated` แตะตารางนี้ได้ | ขึ้น `permission denied for table` |
| **RLS policy** | แตะได้แล้ว เห็นเฉพาะแถวของตัวเอง | คนอื่นอ่านข้อมูลเราได้ |

RLS จำเป็นมาก เพราะเว็บใช้ anon key ที่เปิดเผยในเบราว์เซอร์อยู่แล้ว
ความปลอดภัยอยู่ที่ policy ไม่ใช่การซ่อนคีย์

**เช็กว่าตั้งค่าครบ**: รัน [`supabase/check.sql`](supabase/check.sql) ใน SQL Editor
ทุกบรรทัดต้องขึ้น ✅

### 2. ตั้ง Environment Variables

หาค่าได้ที่ Supabase Dashboard → **Project Settings → API**

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

- **รันในเครื่อง**: สร้างไฟล์ `.env.local` แล้วใส่ 2 บรรทัดนี้
- **บน Vercel**: Project Settings → Environment Variables → เพิ่ม 2 ตัว → **redeploy หนึ่งครั้ง**
  (ค่าที่ขึ้นต้นด้วย `NEXT_PUBLIC_` ถูกฝังตอน build จึงต้อง build ใหม่)

> ใช้ **anon key** เท่านั้น อย่าเอา `service_role` key มาใส่ เพราะมันข้าม RLS ได้ทั้งหมด

ถ้ายังไม่ตั้งค่า หน้า login จะขึ้นคำแนะนำให้เอง แอปไม่พัง

### เข้าสู่ระบบ

สมัครสมาชิกด้วยอีเมล + รหัสผ่านในหน้า `/signup` ได้เลย
ถ้าโปรเจกต์เปิด **Confirm email** ไว้ (ค่าเริ่มต้นของ Supabase)
ต้องเปิดลิงก์ยืนยันในอีเมลก่อนถึงจะเข้าใช้ได้

## Deploy บน Vercel

1. `git init && git add -A && git commit -m "Travel Planner"`
2. push ขึ้น GitHub
3. Vercel → **Add New Project** → Import repo (ตรวจจับ Next.js ให้เอง ไม่ต้องตั้งค่าเพิ่ม)
4. (ไม่บังคับ) ตั้ง `AUTH_USERNAME` / `AUTH_PASSWORD` ใน Environment Variables
5. **Deploy**

## Tech Stack

- **Next.js 16** (App Router, Turbopack) + React 19 + TypeScript
- **Tailwind CSS v4** — ธีมกรม-ทอง (โหมดเข้ม) กำหนดใน `src/app/globals.css` — มีชุดสีสำหรับพิมพ์ PDF แยกใน `@media print` ทุกคู่สีผ่านเกณฑ์ contrast 4.5:1
- **Leaflet + OpenStreetMap** — แผนที่ ไม่ต้องใช้ API key
- **OSRM** (ผ่าน `/api/route`) — ระยะทางจริงตามถนน
- **Nominatim** (ผ่าน `/api/geocode`) — ค้นหาชื่อสถานที่เป็นพิกัด
- **Supabase** — ล็อกอิน (อีเมล+รหัสผ่าน) และฐานข้อมูล พร้อม Row Level Security
- **localStorage** — สำรองข้อมูลไว้ในเครื่องด้วย เผื่อเน็ตหลุดระหว่างแก้แผน

## รูปความทรงจำ

แนบรูปกับจุดแวะได้ในฟอร์มแก้ไขกิจกรรม รูปจะไปโผล่ 3 ที่

1. **หมุดบนแผนที่** — หมุดที่มีรูปจะมีจุด 📷 กำกับ กดแล้วเห็นรูปใน popup
2. **หน้าสรุปแผน** — เรียงใต้แต่ละกิจกรรม
3. **ไฟล์ที่ export** — ทั้ง PNG และ PDF

รูปเก็บใน Supabase Storage **แบบส่วนตัว** (`public = false`) เว็บขอ signed URL
ที่มีอายุทุกครั้งที่จะแสดง คนที่ไม่ได้ล็อกอินด้วยบัญชีเจ้าของเปิดดูไม่ได้

รูปถูกย่อในเบราว์เซอร์ก่อนอัปโหลด (ด้านยาวสุด 1600px, JPEG) เพราะรูปจากมือถือ
มักใหญ่ 3-8 MB ถ้าอัปตรง ๆ จะกินโควตาเร็วและโหลดช้า

## แนะนำลำดับการเดินทาง

หน้าแผนที่จะคำนวณว่าลำดับจุดแวะปัจจุบันเดินทางวนไปมาหรือเปล่า
ถ้ามีทางที่สั้นกว่าจะเสนอให้ พร้อมบอกว่าประหยัดได้กี่ กม.

**ไม่แก้ข้อมูลจนกว่าจะกดยืนยัน** — กดดูลำดับใหม่กับตารางเวลาที่คำนวณให้ก่อนได้
จุดแรกของวันถูกตรึงไว้เสมอ เพราะมักเป็นที่พักหรือจุดนัดพบ

ใช้ nearest neighbour หาคำตอบตั้งต้นแล้วขัดด้วย 2-opt ไม่ใช่คำตอบที่ดีที่สุด
เสมอไป (TSP แบบเป๊ะ ๆ ไม่คุ้ม) แต่ได้ผลดีสำหรับจุดแวะ 5-15 จุดต่อวัน

## บันทึกแผนเป็นไฟล์

ในหน้า **📄 สรุปแผน** มีสองปุ่ม

- **🖼️ PNG** — วาดสรุปลง canvas เองแล้วดาวน์โหลด เหมาะกับส่งในแชท
- **📄 PDF** — เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ เลือกปลายทาง "Save as PDF"

ทั้งสองทางไม่ใช้ไลบรารีเพิ่ม จึงไม่มี dependency ใหม่ในโปรเจกต์

## ข้อจำกัดที่ควรรู้

- **แผนเก็บเป็น JSONB ก้อนเดียวต่อผู้ใช้** (ตาราง `trip_states`) เพราะแอปอ่าน-เขียน
  ทั้งแผนพร้อมกันเสมอ ผลคือ query รายกิจกรรมด้วย SQL ไม่ได้ และถ้าเปิดแก้พร้อมกัน
  2 เครื่อง เครื่องที่บันทึกทีหลังจะทับ — ถ้าวันหลังต้องแชร์แผนหรือ query ราย
  กิจกรรม ค่อยแตกเป็นตารางย่อย
- **ครั้งแรกที่ล็อกอิน** ถ้าเครื่องนั้นมีแผนเก่าใน localStorage ระบบจะยกขึ้นบัญชีให้
  อัตโนมัติ แต่ทำครั้งเดียวตอนบัญชียังไม่มีข้อมูล
- **ค่าเข้าและระยะเวลา** ในหน้าแนะนำเที่ยวเป็นค่าประมาณสำหรับตั้งงบและจัดตาราง
  ควรตรวจสอบกับแหล่งข้อมูลทางการก่อนเดินทางจริง
- **พิกัดสถานที่แนะนำ** ดึงจาก OpenStreetMap บางจุดเป็นตำแหน่งของพื้นที่กว้าง
  (เช่นอุทยานแห่งชาติ) ไม่ใช่ทางเข้าที่แน่นอน ตอนขับจริงควรเช็กกับแอปนำทางอีกครั้ง
- **ประมาณการค่าใช้จ่าย** คิดจากราคาเฉลี่ยในไทย ใช้ตั้งงบตั้งต้นเท่านั้น
  ราคาจริงต่างกันมากตามจังหวัดและฤดูกาล
- **OSRM / Nominatim** เป็น public server มี rate limit และไม่มี SLA — หากเรียกไม่สำเร็จ
  ระบบจะเปลี่ยนไปใช้ระยะทางประมาณการ (เส้นตรง × 1.3) พร้อมแสดงป้ายเตือน
