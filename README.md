# ✈️ Travel Planner

เว็บวางแผนการท่องเที่ยว — จัดตารางกิจกรรมรายวัน คุมงบประมาณแยกหมวด เตรียมของด้วย
Checklist และดูเส้นทาง/ระยะทางบนแผนที่ ออกแบบให้ใช้บนมือถือเป็นหลัก

## ตั้งค่า Supabase (ต้องทำก่อนใช้งาน)

ระบบล็อกอินและฐานข้อมูลใช้ Supabase — ต้องตั้ง 2 อย่างนี้ก่อน

### 1. สร้างตารางในฐานข้อมูล

เปิด Supabase Dashboard → **SQL Editor** → วางไฟล์ [`supabase/schema.sql`](supabase/schema.sql)
ทั้งไฟล์ → กด Run (รันซ้ำได้ ไม่พัง)

สคริปต์นี้สร้างตาราง `trip_states`, bucket `trip-photos` สำหรับเก็บรูป
และตั้งสิทธิ์ 2 ชั้นซึ่งต้องมีทั้งคู่

| ชั้น | ทำอะไร | ถ้าขาด |
| --- | --- | --- |
| `GRANT` | role `authenticated` แตะตารางนี้ได้ | ขึ้น `permission denied for table` |
| **RLS policy** | แตะได้แล้ว เห็นเฉพาะแถวของตัวเอง | คนอื่นอ่านข้อมูลเราได้ |

RLS จำเป็นมาก เพราะเว็บใช้ anon key ที่เปิดเผยในเบราว์เซอร์อยู่แล้ว
ความปลอดภัยอยู่ที่ policy ไม่ใช่การซ่อนคีย์

**เช็กว่าตั้งค่าครบ**: รัน [`supabase/check.sql`](supabase/check.sql) ใน SQL Editor
ทุกบรรทัดต้องขึ้น ✅

### 2. ตั้ง Environment Variables

หาค่าได้ที่ Supabase Dashboard → **Project Settings → API**

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

- **รันในเครื่อง**: สร้างไฟล์ `.env.local` แล้วใส่ 2 บรรทัดนี้
- **บน Vercel**: Project Settings → Environment Variables → เพิ่ม 2 ตัว → **redeploy หนึ่งครั้ง**
  (ค่าที่ขึ้นต้นด้วย `NEXT_PUBLIC_` ถูกฝังตอน build จึงต้อง build ใหม่)

> ใช้ **anon key** เท่านั้น อย่าเอา `service_role` key มาใส่ เพราะมันข้าม RLS ได้ทั้งหมด

ถ้ายังไม่ตั้งค่า หน้า login จะขึ้นคำแนะนำให้เอง แอปไม่พัง

### เข้าสู่ระบบ

สมัครสมาชิกด้วยอีเมล + รหัสผ่านในหน้า `/signup` ได้เลย
ถ้าโปรเจกต์เปิด **Confirm email** ไว้ (ค่าเริ่มต้นของ Supabase)
ต้องเปิดลิงก์ยืนยันในอีเมลก่อนถึงจะเข้าใช้ได้

### แนะนำเที่ยว — โฟลว์ 5 ขั้น

หน้า 🧭 แนะนำเที่ยว เดินตามลำดับนี้ แต่ละขั้นทำงานเดียว

    1. ค้นหา            ช่องพิมพ์ กดแล้วมีรายการขึ้นมาให้เลือก
                        แบ่งเป็น ⭐ คัดมาแนะนำ และ 📍 จาก OpenStreetMap
    2. จังหวัด/อำเภอ     พิมพ์ชื่อจังหวัดได้เลย แล้วกรองต่อด้วยชิปอำเภอ
                        ชิปอำเภอนับรวมทั้งสองแหล่ง
    3. รายละเอียด        กดที่การ์ด เปิดรูป คำอธิบาย เวลาที่ควรไป และเคล็ดลับ
    4. แผนที่           แผนที่เฉพาะจุดนั้นอยู่ในหน้ารายละเอียด
    5. โปรแกรมเที่ยว     ติ๊กหลายที่ แล้วกดสร้างเป็นตารางของวันเดียว
                        เสร็จแล้วมีปุ่ม 🗺️ ดูบนแผนที่ ให้กดไปดูต่อได้เลย

**ช่องค้นหาช่องเดียวคุมทั้งหน้า** — พิมพ์ครั้งเดียวกรองทั้งรายการที่คัดไว้เอง
และการ์ดจาก OpenStreetMap ข้างล่าง ไม่ใช่ต่างคนต่างมีช่องของตัวเอง
และผลลัพธ์อยู่ในจังหวัด (และอำเภอ) ที่เลือกไว้เสมอ

**⭐ = ที่ที่คนมาอำเภอนั้นมักไม่พลาด** — เป็นการคัดโดยคนเขียนข้อมูล
ไม่ใช่คะแนนรีวิวจากที่ไหน จึงใส่แค่ 1-3 แห่งต่ออำเภอ ถ้าติดดาวหมดทุกแห่ง
ดาวก็ไม่มีความหมาย ที่ติดดาวถูกดันขึ้นบนสุดเสมอ

ขั้นที่ 5 เรียงตามลำดับในรายการ เผื่อเวลาเดินทางระหว่างจุด 30 นาที
แก้เวลาทีหลังได้ที่หน้าแผนเที่ยว — ตรงนี้แค่ทำโครงให้ก่อนจะได้ไม่ต้องกรอกทีละอัน

### พื้นที่ทดลอง — อำเภอบ้านแหลม เพชรบุรี

ตั้งใจเริ่มจากอำเภอเดียวให้ครบทั้งโฟลว์ก่อน แทนที่จะลงข้อมูลทั้ง 77 จังหวัด
ตั้งแต่แรก จะได้รู้ว่าหน้าจอกับโครงข้อมูลใช้ได้จริงก่อนขยาย

7 แห่ง พิกัดยืนยันจาก OpenStreetMap ทุกจุด (Nominatim + Overpass)

| สถานที่ | ประเภท |
| --- | --- |
| ⭐ วัดเขาตะเครา | วัด |
| ⭐ ปากทะเล | ดูนก |
| ⭐ บางตะบูน | ชุมชนประมง |
| จุดชมนาเกลือ Art of Salt | นาเกลือ |
| สถานีพัฒนาทรัพยากรป่าชายเลนที่ 6 | ป่าชายเลน |

ขยายไปอำเภออื่นได้โดยเติมใน `src/data/provinces/*.ts` ใส่ `district` ให้ตรงกับ

### เพิ่มเติมจาก OpenStreetMap

รายการที่คัดไว้เองมีจังหวัดละ 4-8 แห่ง ซึ่งน้อยเกินกว่าจะวางแผนได้จริง
การ์ด **🛕 วัด คาเฟ่ ร้านดัง** จึงดึงจากชุดข้อมูล OpenStreetMap มาเสริม
กรองตามอำเภอที่เลือก แบ่งหมวดด้วยปุ่ม วัด / ที่เที่ยว / คาเฟ่ / ร้านอาหาร

| ชุดข้อมูล | จำนวน | ระบุอำเภอแล้ว |
| --- | ---: | ---: |
| ที่เที่ยว (รวมวัด 291 แห่ง) | 2,540 | 99.6% |
| ร้านอาหารและคาเฟ่ | 1,454 | 99.8% |

ชุดนี้ไม่มีคำอธิบายและค่าเข้า เพราะ OSM ไม่ได้เก็บไว้ ทุกแถวจึงมีลิงก์
**เปิดใน Google Maps** ให้ไปดูรูป รีวิว และเวลาเปิด-ปิดต่อ

ในการ์ดนี้ **⭐ = มีหน้า Wikipedia** ซึ่งเป็นสัญญาณเดียวที่ OSM มีว่าที่ไหนดังจริง
ต่างจาก ⭐ ในรายการที่คัดไว้เองซึ่งเป็นการคัดโดยคนเขียนข้อมูล — ช่องค้นหา
เขียนกำกับไว้ที่หัวข้อกลุ่มทั้งสองแบบ จะได้ไม่สับสน

### รูปประกอบสถานที่

หน้ารายละเอียดดึงรูปจาก **วิกิพีเดียภาษาไทย** มาแสดง ไม่ต้องใช้ API key
และไม่ต้องผูกบัตรเครดิต ต่างจาก Google Places

**ไม่ใช่ทุกที่ที่มีรูป** และนั่นตั้งใจ — เคยลองค้นรูปตามพิกัดใน Wikimedia Commons
แล้วได้รูปที่ไม่เกี่ยวเยอะมาก (ค้นรอบบางตะบูนได้รูปหนังสือพิมพ์กับปลาทู)
รูปผิดแย่กว่าไม่มีรูป เพราะผู้ใช้เอาไว้ตัดสินใจว่าจะไปหรือไม่ไป

การค้นของวิกิพีเดียคืนหน้าที่ "ใกล้เคียง" มาเสมอ ไม่เคยตอบว่าไม่เจอ จึงมีด่านกรอง
ที่ `src/lib/place-photo.ts` — ทิ้งหน้าที่เป็นเขตปกครอง (อำเภอ/ตำบล/จังหวัด)
และทิ้งหน้าที่ชื่อสั้นกว่าและอยู่ข้างในชื่อสถานที่ ซึ่งมักเป็นคนละที่ที่ชื่อบังเอิญซ้อนกัน

| สถานที่ | หน้าที่ค้นเจอ | ผล |
| --- | --- | --- |
| หาดชะอำ | หาดชะอำ | ✅ ใช้ |
| หาดชะอำ | อำเภอชะอำ | ❌ เขตปกครอง คนละเรื่อง |
| ตลาดสดวัดต้นสน | วัดต้นสน | ❌ ชื่อซ้อนกันแต่คนละที่ |
| วัดพระธาตุดอยสุเทพ | วัดพระธาตุดอยสุเทพราชวรวิหาร | ✅ ที่เดียวกัน ชื่อทางการยาวกว่า |

## โครงเมนู

**มือถือ — แถบล่าง 4 เมนู** เรียงตามลำดับที่ใช้จริงตอนวางแผนทริป
หาแรงบันดาลใจ → ดูว่าอยู่ตรงไหน → ลงแผน

    หน้าหลัก   แนะนำเที่ยว   แผนที่   แผนเที่ยว

**โปรไฟล์อยู่มุมขวาบน** ไม่ได้อยู่บนแถบล่างและไม่อยู่ในแถบข้างซ้าย
เพราะถ้ามีสองทางเข้าไปที่เดียวกันคนจะลังเลว่าต่างกันยังไง

กดแล้วเปิดเมนูสั้น ๆ มีแค่ **ประวัติส่วนตัว** กับ **ออกจากระบบ**
เมนูบัญชีที่ยาวเกินไปทำให้ต้องอ่านทุกบรรทัดก่อนจะเจอสิ่งที่ต้องการ
ส่วนเมนูอื่นของแอปอยู่ในแถบข้าง (จอใหญ่) และแถบล่าง (จอเล็ก) อยู่แล้ว
สวิตช์โหมดมืดย้ายไปอยู่ในหน้าประวัติส่วนตัว เพราะเป็นการตั้งค่า ไม่ใช่ทางลัด

**จอใหญ่ — แถบข้างซ้าย** ตัดสองเมนูที่มีทางเข้าอื่นอยู่แล้วออก จะได้ไม่มี
สองทางเข้าไปที่เดียวกัน — **โปรไฟล์** อยู่ที่ปุ่มมุมขวาบน ส่วน **แผนเที่ยว**
เข้าจากชื่อทริปด้านบนของแถบข้าง จากหน้าหลัก และจากการ์ดต่าง ๆ (มีลิงก์ไปรวม 9 จุด)
ด้านบนมีชื่อแผนที่เปิดอยู่ (กดสลับแผนได้) และปุ่ม **«** ย่อแถบเหลือแค่ไอคอน
คืนพื้นที่ให้เนื้อหาราว 12rem ซึ่งมีผลจริงกับหน้าที่มีตารางและแผนที่
จำสถานะไว้ใน `localStorage` เพราะคนที่ชอบแบบย่อมักอยากให้ย่อไว้ตลอด

บนจอเล็กที่ไม่มีแถบข้าง ชื่อแผนอยู่บนแถบบนซ้ายเหมือนเดิม

เมนูที่เปิดอยู่บนแถบล่างจะมีเม็ดยาสีแบรนด์รองไอคอนไว้ ทำให้เห็นได้จากหางตา
โดยไม่ต้องอ่านตัวหนังสือซึ่งเล็กมากในแถบขนาดนั้น

## Deploy บน Vercel

1. `git init && git add -A && git commit -m "Travel Planner"`
2. push ขึ้น GitHub
3. Vercel → **Add New Project** → Import repo (ตรวจจับ Next.js ให้เอง ไม่ต้องตั้งค่าเพิ่ม)
4. (ไม่บังคับ) ตั้ง `AUTH_USERNAME` / `AUTH_PASSWORD` ใน Environment Variables
5. **Deploy**

## รันในเครื่อง (ถ้าต้องการ)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # ตรวจ TypeScript + สร้าง production build
npx eslint .
```

## Tech Stack

- **Next.js 16** (App Router, Turbopack) + React 19 + TypeScript
- **Tailwind CSS v4** — ธีมกรมน้ำเงิน-ฟ้า เฉดสีมาจากโลโก้ กำหนดใน `src/app/globals.css` มี 3 ชุด: โหมดมืด (`@theme`), โหมดสว่าง (`:root[data-theme="light"]`) และโหมดพิมพ์ PDF (`@media print`) ทุกคู่สีผ่านเกณฑ์ contrast 4.5:1 ตรวจได้ด้วย `node scripts/check-contrast.js`
- **ไอคอนแถบเมนูเป็น SVG เส้นเรียบ** วาดในโค้ดที่ `src/components/NavIcon.tsx` ไม่ได้ลงไลบรารีไอคอน ใช้ `currentColor` จึงเปลี่ยนสีตามสถานะ active และตามโหมดมืด/สว่างได้เอง ต่างจากอิโมจิที่เป็นภาพสีตายตัวและหน้าตาต่างกันไปตามระบบปฏิบัติการ
- **อิโมจิใช้เท่าที่สื่อความหมาย** — ชื่อหน้า หัวข้อ และป้ายกำกับเป็นตัวหนังสือล้วน เก็บอิโมจิไว้เฉพาะที่บอกอะไรจริง ๆ (⭐ ที่ดัง · ⚠️ คำเตือน · ✓ ทำแล้ว) ทุกหน้ามีอิโมจิเท่ากับไม่มีอันไหนเด่น และไปแย่งสายตากับปุ่ม
- **ปุ่มหลักเด่นกว่าทุกอย่างรอบตัว** — สีทึบเต็ม ตัวหนา มีเงา สูง 3rem ส่วนปุ่มรองตั้งใจให้เงียบ ขอบบางพื้นเรียบ จะได้ไม่แย่งสายตากันเองในการ์ดเดียวกัน
- **สลับโหมดมืด/สว่าง** — เป็นสวิตช์เปิดปิด บอกสถานะปัจจุบันในตัว จำค่าไว้ใน `localStorage` ยังไม่เคยเลือก = ตามการตั้งค่าของเครื่อง มีสคริปต์เล็ก ๆ ใน `<head>` ตั้งโหมดก่อนหน้าจอถูกวาด จะได้ไม่เห็นจอวาบสลับสี
- **Leaflet + OpenStreetMap** — แผนที่ ไม่ต้องใช้ API key
- **OSRM** (ผ่าน `/api/route`) — ระยะทางจริงตามถนน
- **Nominatim** (ผ่าน `/api/geocode`) — ค้นหาชื่อสถานที่เป็นพิกัด
- **Supabase** — ล็อกอิน (อีเมล+รหัสผ่าน) และฐานข้อมูล พร้อม Row Level Security
- **localStorage** — สำรองข้อมูลไว้ในเครื่องด้วย เผื่อเน็ตหลุดระหว่างแก้แผน

## รูปความทรงจำ

แนบรูปกับจุดแวะได้ในฟอร์มแก้ไขกิจกรรม รูปจะไปโผล่ 3 ที่

1. **หมุดบนแผนที่** — หมุดที่มีรูปจะมีจุด 📷 กำกับ กดแล้วเห็นรูปใน popup
2. **หน้าสรุปแผน** — เรียงใต้แต่ละกิจกรรม
3. **ไฟล์ที่ export** — ทั้ง PNG และ PDF

รูปเก็บใน Supabase Storage **แบบส่วนตัว** (`public = false`) เว็บขอ signed URL
ที่มีอายุทุกครั้งที่จะแสดง คนที่ไม่ได้ล็อกอินด้วยบัญชีเจ้าของเปิดดูไม่ได้

รูปถูกย่อในเบราว์เซอร์ก่อนอัปโหลด (ด้านยาวสุด 1600px, JPEG) เพราะรูปจากมือถือ
มักใหญ่ 3-8 MB ถ้าอัปตรง ๆ จะกินโควตาเร็วและโหลดช้า

## ประมาณการค่าใช้จ่ายตามวิธีเดินทาง

เลือก **วิธีเดินทางหลัก** ในการ์ด &ldquo;รูปแบบการเดินทาง&rdquo; แล้วตัวประมาณการ
จะคิดค่าตั๋วไป-กลับให้ด้วย ไม่ใช่แค่ค่าเดินทางในพื้นที่

ตัวอย่างทริป 3 วัน 2 คน แบบปานกลาง

| วิธีเดินทาง | ค่าเดินทาง | รวมทั้งทริป |
| --- | ---: | ---: |
| ไม่ระบุ | 3,000 | 16,400 |
| 🚶 เดิน/ในเมือง | 600 | 14,000 |
| 🚇 รถไฟฟ้า | 1,100 | 14,500 |
| 🚗 รถยนต์ | 5,100 | 18,500 |
| 🚆 รถไฟ | 6,800 | 20,200 |
| ✈️ เครื่องบิน | 10,800 | 24,200 |

ค่าเดินทางแยกเป็น 2 ก้อน — **ค่าตั๋วไป-กลับต่อคน** กับ **ค่าเดินทางในพื้นที่ต่อวัน**
ก้อนหลังปรับตามวิธีเดินทางด้วย เพราะคนขับรถมาเองใช้รถคันเดิมตลอด
ส่วนคนที่บินมาต้องเช่ารถหรือเรียกแท็กซี่

## แผนเที่ยวอยู่ในหน้าตั้งค่าทริป

ตารางกิจกรรมรายวันอยู่ในหน้า **ตั้งค่าทริป** ที่เดียวกับที่ตั้งจำนวนวัน
และเลือกจังหวัด จะได้ไม่ต้องสลับหน้าไปมาระหว่างตั้งค่ากับจัดตาราง

    ⚙️ ตั้งค่าทริป
    ├ 📅 รูปแบบการเดินทาง   จำนวนวัน วันเริ่ม จำนวนคน วิธีเดินทางหลัก
    ├ 🧳 ข้อมูลทริป
    ├ 🗺️ แพลนการเที่ยว      เลือกจังหวัด/อำเภอ
    ├ 📋 แผนเที่ยว          แท็บวัน ช่วงการเดินทาง กิจกรรม แนะนำ ร้านอาหาร
    ├ 💰 งบประมาณ
    └ 💾 ข้อมูลที่บันทึกไว้

เส้นทาง `/itinerary` เดิมยังใช้ได้ เปลี่ยนทางไป `/settings#plan` ให้เอง

## ช่วงการเดินทางรายวัน

วันเดียวมักใช้หลายวิธี จึงแยกเก็บเป็น **ช่วง ๆ** แทนวิธีเดินทางเดียวต่อวัน

| ช่วง | จาก | ถึง | วิธี |
| --- | --- | --- | --- |
| 1 | กรุงเทพฯ | เชียงใหม่ | ✈️ เครื่องบิน |
| 2 | เชียงใหม่ | ดอยอินทนนท์ | 🚗 รถยนต์ |

ช่วงถัดไปเติมต้นทางให้อัตโนมัติจากปลายทางของช่วงก่อน แต่ละช่วงใส่บันทึกได้
เช่นเลขเที่ยวบิน แล้วหน้าหลัก หน้าสรุป และไฟล์ PNG/PDF จะแสดงเป็นสายเดียว
เช่น กรุงเทพมหานคร ✈️ เชียงใหม่ 🚗 ดอยอินทนนท์

ข้อมูลเดิมที่เก็บวิธีเดินทางเดียวต่อวันจะถูกย้ายมาเป็นช่วงแรกให้อัตโนมัติ

## เพิ่มสถานที่ลงแผน

ในฟอร์มเพิ่มรายการ **สถานที่เป็นช่องหลัก** และ **กิจกรรมเป็นช่องย่อยลงมา**

    📍 สถานที่          กดที่ช่อง -> ที่ดังในจังหวัดนั้นขึ้นมาให้เลือกทันที
    │                   เลือกได้หลายที่รวดเดียว แต่ละที่จะเป็นคนละรายการ
    │                   หรือพิมพ์ชื่อเองก็ได้ ทุกแถวมีลิงก์ 🗺️ เปิด Google Maps
    └ 🎯 กิจกรรมที่นี่   ใส่ได้หลายอย่าง เรียงลำดับและลบทีละอันได้
                        ไม่ใส่ก็ได้ จะใช้ชื่อสถานที่เป็นชื่อรายการให้

### เลือกหลายที่รวดเดียว

วางแผนวันหนึ่งมักนึกออกทีเดียวหลายที่ เลือกไว้เลยแล้วกดบันทึกครั้งเดียว
ระบบจะแยกเป็นคนละรายการและ**เรียงเวลาต่อกันให้อัตโนมัติ เผื่อเดินทาง 30 นาที**
โดยใช้เวลาที่ควรเผื่อกับค่าเข้าของแต่ละที่เอง

    09:00–10:30  วัดพระธาตุดอยสุเทพ   50 บาท
    11:00–13:30  ย่านนิมมานเหมินท์      ฟรี
    14:00–16:00  ถนนคนเดินท่าแพ        ฟรี

พอเลือกตั้งแต่ 2 ที่ขึ้นไป ช่องกิจกรรม รูป และรายละเอียดจะถูกซ่อน
เพราะกำกวมว่าเป็นของที่ไหน ไปเพิ่มทีหลังโดยกด ✏️ ที่การ์ดของแต่ละที่แทน

### ที่เดียวทำได้หลายกิจกรรม

ที่เดียวมักทำหลายอย่าง เช่นไปวัดแล้วทั้งไหว้พระ ถ่ายรูป และชิมของกินหน้าวัด
พิมพ์แล้วกด Enter เพื่อเพิ่มทีละอัน หรือเลือกจากรายการที่แนะนำก็ได้
เวลาที่ควรเผื่อกับค่าใช้จ่ายจะเติมให้จากกิจกรรม**แรก**เท่านั้น
เพราะรายการหนึ่งมีช่องค่าใช้จ่ายช่องเดียว ถ้าให้ทุกอันมาทับ ตัวเลขที่ปรับเองไว้จะหาย

รายการที่ขึ้นมาให้เลือกมี 3 ชั้น

1. **⭐ ที่ดังในจังหวัดนั้น** — ข้อมูลที่คัดไว้เอง ขึ้นทันทีไม่ต้องรอเน็ต
   เลือกแล้วเติมพิกัด เวลาที่ควรเผื่อ กับค่าเข้าให้เลย จังหวัดละ 4-8 แห่ง
2. **📍 ที่เที่ยวอื่นในจังหวัด** — ดึงจาก OpenStreetMap ไว้ล่วงหน้า
   เฉลี่ยจังหวัดละ 33 แห่ง มีชื่อ ประเภท และพิกัด แต่ไม่มีคำอธิบายหรือค่าเข้า
3. **🔎 ค้นจากแผนที่** — ค้นสดตอนพิมพ์ สำหรับที่ที่ไม่มีในสองชั้นแรก
   เช่นโรงแรมหรือร้านเฉพาะเจาะจง พิมพ์ 3 ตัวอักษรขึ้นไปแล้วหน่วงครึ่งวินาทีถึงจะยิง

> **หมายเหตุเรื่อง Google Maps** — ข้อมูลสถานที่ไม่ได้ดึงจาก Google Places API
> เพราะ API นั้นต้องเปิดบัญชีเรียกเก็บเงินก่อนถึงจะใช้ได้ แม้ในโควตาฟรี
> เว็บนี้ใช้ข้อมูลที่คัดไว้เอง (ตรวจพิกัดกับ OpenStreetMap แล้ว) บวกกับค้นสด
> จาก OpenStreetMap ส่วนลิงก์ 🗺️ ในทุกแถวเปิด Google Maps ให้ดูรูป รีวิว
> และเวลาเปิดปิดต่อได้ ซึ่งเป็นส่วนที่ Google ทำได้ดีกว่า

## ค้นหากิจกรรม

ช่องชื่อกิจกรรมพิมพ์เองก็ได้ ค้นก็ได้ พิมพ์ **เดินป่า** แล้วจะเจอที่เดินป่า
ของจังหวัดที่เลือกไว้ก่อน (ภูกระดึง ภูเรือ ดอยอินทนนท์) เลือกแล้วเติม
รายละเอียด เวลา ค่าเข้า และพิกัดให้เลย

ค้นจากคำอธิบายและทิปด้วย ไม่ใช่แค่ชื่อ และมีกลุ่มคำพ้องให้ เพราะข้อมูลจริง
เขียนว่า &ldquo;อุทยานแห่งชาติภูกระดึง ต้องเดินขึ้น 5.5 กม.&rdquo; ซึ่งไม่มีคำว่า
เดินป่าอยู่เลย ถ้าเทียบตรงตัวจะไม่เจออะไร

## จังหวัดและวิธีเดินทางรายวัน

แต่ละวันในแผนระบุได้ว่าไปจังหวัดไหนและเดินทางด้วยอะไร มี 9 วิธีให้เลือก
พร้อมช่องจดรายละเอียด เช่นเลขเที่ยวบินหรือขบวนรถไฟ

ข้อมูลนี้ไปโผล่ที่ **แท็บวัน** (เป็น emoji), **หน้าหลัก**, **หน้าสรุปแผน**
และ **ไฟล์ที่ export** ทั้ง PNG และ PDF

รายการจังหวัดจะเอาจังหวัดที่เลือกไว้ในแพลนการเที่ยวขึ้นก่อน
แต่ยังเลือกจังหวัดอื่นได้ เผื่อแวะระหว่างทางโดยไม่ได้วางแผนไว้

### 🚇 รถไฟฟ้า (เฉพาะ กทม. และปริมณฑล)

ตัวเลือก **รถไฟฟ้า** จะโผล่เฉพาะเมื่อเลือกจังหวัดเป็นกรุงเทพฯ นนทบุรี
ปทุมธานี หรือสมุทรปราการ พอเลือกแล้วจะมีตัวค้นเส้นทาง BTS/MRT ให้

เลือกสถานีขึ้น-ลง แล้วระบบจะบอกว่าต้องนั่งสายไหน กี่สถานี
เปลี่ยนสายที่ไหนบ้าง และใช้เวลาประมาณเท่าไร

ข้อมูล 7 สาย / 172 สถานี ดึงจาก OpenStreetMap ด้วย `scripts/gen-metro.js`
**จุดเปลี่ยนสายหาจากระยะทาง ไม่ใช่ชื่อ** เพราะสถานีเดียวกันมักคนละชื่อข้ามระบบ
เช่น อโศก (BTS) กับ สุขุมวิท (MRT) หรือ ศาลาแดง กับ สีลม

## ร้านอาหารและคาเฟ่

การ์ด **🍜 ร้านดังในจังหวัด** ในหน้าแผนเที่ยว — ดูได้ตั้งแต่ยังไม่มีจุดแวะ
แค่เลือกจังหวัดไว้ก็พอ มี **ช่องค้นหา** พิมพ์ชื่อร้านหรือประเภทอาหารได้
(เช่น "กาแฟ" "อาหารทะเล") กดครั้งเดียวใส่ลงแผน พร้อมลิงก์ **เปิดใน Google Maps**
เพื่อดูรีวิวและรูปต่อ

ร้านที่มีคนเขียนถึงใน Wikipedia ติดดาว ⭐ และถูกดันขึ้นบนสุดเสมอ
เพราะเป็นสัญญาณเดียวที่ OSM มีว่าร้านไหนดังจริง

### ฐานข้อมูลร้าน 1,454 ร้าน ครบ 77 จังหวัด

ไทยมีร้านอาหารใน OSM หลายหมื่นแห่ง ถ้าเอามาหมดรายการจะท่วมไปด้วยร้านข้างทาง
จึงคัดเฉพาะร้านที่มีร่องรอยว่ามีตัวตนจริงจัง

- มีเว็บไซต์ เบอร์โทร หรือบอกเวลาเปิดปิด
- หรือมีคนเขียนถึงใน Wikipedia/Wikidata (ติดป้าย ⭐ ในรายการ)
- ตัดร้านเชนที่มีทุกห้างออก เพราะไม่ใช่จุดหมายของทริป

ได้มา 5,601 ร้าน เหลือ 1,454 หลังกรอง เฉลี่ยจังหวัดละ 19 ร้าน
บางจังหวัดได้น้อยกว่า 5 เพราะยังไม่ค่อยมีคนลงข้อมูล ใช้การค้นสดแทนได้

สร้างใหม่ได้ด้วย

```bash
node scripts/fetch-province-boundaries.js boundaries.json
node scripts/fetch-restaurants.js restaurants.json
node scripts/build-restaurants.js restaurants.json boundaries.json
node scripts/validate-restaurants.js
```

ข้อมูลมาจาก **OpenStreetMap** (ฟรี ไม่ต้องมี API key) ซึ่งอาสาสมัครช่วยกันลง
จึงอาจไม่ครบหรือไม่อัปเดตเท่า Google เวลาจะไปจริงควรเช็กเวลาเปิด-ปิดอีกที
ถ้าอยากได้คะแนนรีวิวและรูปจาก Google โดยตรงต้องสมัคร Google Places API
ซึ่งต้องเปิด billing และมีค่าใช้จ่ายต่อการเรียก

อยู่บนสุด และปุ่มมุมซ้ายบนบอกว่ากำลังเปิดแผนไหนอยู่ กดแล้วเห็นรายการทั้งหมด
**สร้างแผนใหม่ได้โดยแผนเดิมยังอยู่ครบ** สลับกลับไปดูได้ตลอด ทำสำเนาและลบได้

ทุกแผนเก็บอยู่ในแถวเดียวกันของตาราง `trip_states` (คอลัมน์ `data` เป็น JSON)
จึง **ไม่ต้องแก้อะไรในฐานข้อมูล** ผู้ใช้เดิมที่มีแผนอยู่แล้วจะถูกย้ายมาเป็น
แผนแรกในคลังให้อัตโนมัติ ตรวจด้วย `node --experimental-strip-types --import
./scripts/alias-hooks.mjs scripts/test-storage.mts`

## ค่าน้ำมันตามระยะทางจริง

การ์ดในหน้างบจะโผล่มาเองเมื่อทริปมีการขับรถ (ดูทั้งวิธีเดินทางหลักและ
ช่วงเดินทางรายวัน เพราะบางทริปบินไปแล้วเช่ารถต่อ)

ระยะทางเอาจาก **OSRM** ซึ่งเป็นระยะตามถนนจริงไม่ใช่เส้นตรง รวมทุกวันในแผน
เลือกประเภทรถได้ 6 แบบ หรือกรอกอัตราสิ้นเปลืองกับราคาน้ำมันเองก็ได้
กดปุ่มเดียวเพิ่มเข้าเป็นค่าใช้จ่ายหมวดเดินทาง

ยังไม่รวมค่าทางด่วน ค่าจอดรถ และระยะจากบ้านไปจังหวัดปลายทาง

## เอาแผนที่ไปใช้ตอนไม่มีเน็ต

**เว็บสั่งให้แอป Google Maps ดาวน์โหลดแผนที่ออฟไลน์เองไม่ได้** Google ไม่มี API
ให้ทำ การ์ดในหน้าแผนที่จึงให้สามทางเลือก

| ทาง | ทำอะไร | ออฟไลน์ได้จริงไหม |
| --- | --- | --- |
| 🗺️ เปิดใน Google Maps | ส่งเส้นทางเข้าแอป แล้วกดบันทึกออฟไลน์ในแอปเอง | ได้ แต่ต้องกดในแอป |
| ⬇️ ไฟล์ GPX | เปิดใน Organic Maps / OsmAnd ที่มีแผนที่ออฟไลน์ทั้งประเทศ | ได้เต็มตัว |
| ⬇️ ไฟล์ KML | นำเข้า Google My Maps เห็นในแอปที่ "ที่บันทึกไว้" | ต้องมีเน็ตตอนเปิด |

Google Maps รับจุดแวะกลางทางได้แค่ 9 จุด (รวมต้นทางปลายทางเป็น 11)
ถ้าวันนั้นมีจุดเยอะกว่านั้น ลิงก์จะพาไปเท่าที่รับได้ ส่วนไฟล์ GPX/KML มีครบทุกจุด

## งบรายหมวดผูกกับงบรวม

การ์ด **การแบ่งงบลงหมวด** บอกว่าแบ่งไปแล้วเท่าไร เหลือเท่าไร และแต่ละหมวด
คิดเป็นสัดส่วนกี่เปอร์เซ็นต์ พร้อมสองปุ่ม

- **เกลี่ยส่วนที่เหลือ** — แบ่งเงินที่ยังไม่ได้จัดสรรลงหมวดที่ยังว่าง
  (ถ้าตั้งครบทุกหมวดแล้วจะเกลี่ยตามสัดส่วนเดิม ไม่ใช่หารเท่ากัน)
- **ปรับงบรวม = ผลรวมหมวด** — ยกงบรวมให้เท่ากับที่แบ่งไว้จริง

เศษจากการปัดยกไปให้หมวดสุดท้าย ผลรวมจึงตรงกับงบรวมเป๊ะ ไม่ขาดไปหนึ่งสองบาท

### ป๊อปอัปเตือนเกินงบ

เด้งเตือนอัตโนมัติจากทุกหน้า (mount อยู่ใน layout) เพราะการเพิ่มค่าใช้จ่าย
เกิดที่หน้าแผนเที่ยวและหน้าแนะนำเที่ยวได้ด้วย ไม่ใช่แค่หน้างบ

เตือนสองกรณี

| กรณี | ตัวอย่าง |
| --- | --- |
| **เกินงบรวม** | ตั้งงบ 10,000 ใช้ไป 12,000 |
| **เกินเฉพาะหมวด** | ตั้งงบอาหาร 3,000 ใช้ไป 5,000 ทั้งที่งบรวม 20,000 ยังเหลือ |

กรณีหลังเป็นจุดที่คนพลาดบ่อยกว่า เพราะงบรวมมักตั้งเผื่อไว้จนไม่มีอะไรเตือน
หมวดที่ยังไม่ได้ตั้งงบจะไม่ถูกนับว่าเกิน ป๊อปอัปจึงไม่เด้งพร่ำเพรื่อ

## แนะนำลำดับการเดินทาง

หน้าแผนที่จะคำนวณว่าลำดับจุดแวะปัจจุบันเดินทางวนไปมาหรือเปล่า
ถ้ามีทางที่สั้นกว่าจะเสนอให้ พร้อมบอกว่าประหยัดได้กี่ กม.

**ไม่แก้ข้อมูลจนกว่าจะกดยืนยัน** — กดดูลำดับใหม่กับตารางเวลาที่คำนวณให้ก่อนได้
จุดแรกของวันถูกตรึงไว้เสมอ เพราะมักเป็นที่พักหรือจุดนัดพบ

ใช้ nearest neighbour หาคำตอบตั้งต้นแล้วขัดด้วย 2-opt ไม่ใช่คำตอบที่ดีที่สุด
เสมอไป (TSP แบบเป๊ะ ๆ ไม่คุ้ม) แต่ได้ผลดีสำหรับจุดแวะ 5-15 จุดต่อวัน

## ผู้ช่วย AI (Gemini)

กดปุ่ม 💬 มุมขวาล่างได้ทุกหน้า หรือเปิดหน้าเต็มที่เมนู **👤 โปรไฟล์ → 💬 ผู้ช่วย AI**

ผู้ช่วยรู้ 2 อย่าง — **วิธีใช้เว็บนี้** (หน้าไหนทำอะไร ปุ่มอยู่ตรงไหน)
และ **ข้อมูลทริปที่คุณกรอกไว้** จึงถามได้ทั้ง "เพิ่มรูปความทรงจำยังไง"
และ "งบเหลือเท่าไร"

### ตั้งค่า

1. ขอ API key ฟรีที่ [Google AI Studio](https://aistudio.google.com/apikey)
2. บน Vercel → Project Settings → Environment Variables เพิ่ม

   | ชื่อ | ค่า |
   | --- | --- |
   | `GEMINI_API_KEY` | คีย์ที่ได้มา |
   | `GEMINI_MODEL` | **ไม่ต้องตั้ง** — แอปหารุ่นที่คีย์ใช้ได้เอง |

3. Redeploy หนึ่งครั้ง

> ⚠️ **อย่าใส่ `NEXT_PUBLIC_` นำหน้า** คีย์นี้ต่างจาก anon key ของ Supabase
> ตรงที่ไม่มี Row Level Security คุ้มกัน ถ้าหลุดไปอยู่ในเบราว์เซอร์
> ใครก็เอาไปยิงจนโควตาหมดได้ คีย์จึงอยู่ฝั่งเซิร์ฟเวอร์ที่ `/api/chat` เท่านั้น

ถ้ายังไม่ตั้งค่า ส่วนอื่นของเว็บใช้ได้ปกติ หน้าผู้ช่วยจะขึ้นวิธีตั้งค่าแทน

### เรื่องชื่อรุ่น

Google ปลดรุ่นเก่าออกจากผู้ใช้ใหม่เรื่อย ๆ คีย์ที่ออกใหม่จะเรียก
`gemini-2.5-flash` ไม่ได้แล้ว (ตอบ 404 พร้อมข้อความแนะให้ใช้รุ่นใหม่กว่า)
ค่าเริ่มต้นตอนนี้คือ `gemini-3.6-flash`

ถ้ารุ่นเริ่มต้นใช้ไม่ได้ แอปจะไปถาม Google ว่าคีย์นี้มีรุ่นอะไร แล้ว**ไล่ยิงจริง
ทีละตัว**จนกว่าจะผ่าน — เช็กจากรายชื่ออย่างเดียวไม่พอ เพราะรุ่นที่ถูกปลดแล้ว
ยังโผล่อยู่ในรายชื่อแต่เรียกไม่ได้ รุ่นที่ผ่านจะถูกจำไว้ ไม่ต้องหาใหม่ทุกครั้ง

### หน้าตรวจการตั้งค่า

ล็อกอินแล้วเปิด `/api/chat` ในเบราว์เซอร์ จะได้ JSON บอกว่า

| ฟิลด์ | ความหมาย |
| --- | --- |
| `keyMissing` | ยังไม่ได้ตั้งคีย์หรือเปล่า |
| `envModelRaw` | ค่า `GEMINI_MODEL` ดิบ ๆ ที่เซิร์ฟเวอร์เห็น (เห็นช่องว่างที่ติดมาด้วย) |
| `envModelCleaned` | ค่าเดียวกันหลังล้างแล้ว ถ้าเป็น `""` แปลว่าตั้งผิดรูปจนใช้ไม่ได้ |
| `modelInUse` | รุ่นที่จะถูกส่งไปจริง |
| `candidatesTop` | รุ่นสำรองที่คีย์นี้มี |
| `testCall` | ผลยิงทดสอบจริงหนึ่งครั้ง พร้อมข้อความจาก Google ถ้าพลาด |

ไม่คืนตัวคีย์ออกมา บอกแค่ว่ามีหรือไม่และยาวเท่าไร

### ตรวจคีย์ในเครื่อง

เจอ error เกี่ยวกับคีย์หรือชื่อรุ่น รันตัวนี้ดูได้เลย ไม่ต้องรอ deploy
มันจะลิสต์รุ่นที่คีย์ใช้ได้ แล้วยิงทดสอบจริงหนึ่งครั้ง ถ้าพลาดจะพิมพ์ข้อความดิบ
ที่ Google ส่งมาให้ดูทั้งก้อน

```bash
GEMINI_API_KEY=AIza... node scripts/list-gemini-models.js
```

ถ้าอยากล็อกรุ่นไว้เอง ค่อยตั้ง `GEMINI_MODEL` ทีหลังได้ — ใส่**ชื่อล้วน ๆ**
เช่น `gemini-3.6-flash` ห้ามใส่เครื่องหมายคำพูดครอบ ห้ามมีช่องว่าง และไม่ต้องมี
คำนำหน้า `models/` (ถ้าใส่มาแอปจะล้างให้ แต่ถ้าล้างแล้วยังผิดรูปจะใช้ค่าเริ่มต้นแทน)

### สิ่งที่ควรรู้ก่อนใช้

- **ข้อมูลทริปถูกส่งไปที่ Google ทุกครั้งที่ถาม** — ชื่อทริป จังหวัด กิจกรรม
  และตัวเลขงบ (ไม่ส่งรูปและพิกัด) มีบรรทัดบอกไว้ใต้ช่องแชทด้วย
- โควตาฟรีมีลิมิตต่อนาทีและต่อวัน ถ้าชนจะขึ้นข้อความให้รอสักครู่
- ผู้ช่วยบอกวิธีได้อย่างเดียว **แก้ข้อมูลในเว็บให้ไม่ได้** ต้องกดเอง
- ไม่มีข้อมูลสด เช่น อากาศ ราคาตั๋ววันนี้ หรือร้านเปิดไหม
- ประวัติแชทเก็บใน localStorage ของเครื่องนี้ ไม่ได้ซิงก์ข้ามเครื่องเหมือนข้อมูลทริป

## ติดตั้งเป็นแอป (PWA)

เปิดเว็บบนมือถือแล้วติดตั้งลงหน้าจอโฮมได้ เปิดมาเต็มจอไม่มีแถบที่อยู่ของเบราว์เซอร์

| เครื่อง | วิธีติดตั้ง |
| --- | --- |
| Android (Chrome) | เมนู ⋮ → **ติดตั้งแอป** หรือกดแถบที่เด้งขึ้นมาเอง |
| iPhone/iPad (Safari) | ปุ่มแชร์ → **เพิ่มลงในหน้าจอโฮม** |
| คอมพิวเตอร์ (Chrome/Edge) | ไอคอนติดตั้งท้ายช่องที่อยู่ |

กดค้างที่ไอคอนแอปจะมีทางลัดไป **แผนเที่ยว · แผนที่ · งบประมาณ** ได้เลย

### เรื่องออฟไลน์

**ยังใช้งานตอนไม่มีเน็ตไม่ได้** เพราะทุกหน้าต้องตรวจสิทธิ์กับ Supabase ก่อน
service worker จึงแคชแค่ไฟล์คงที่ (ไอคอน ฟอนต์ สคริปต์) ให้เปิดครั้งถัดไปเร็วขึ้น
ถ้าเน็ตหลุดจะขึ้นหน้าบอกให้ลองใหม่ แทนที่จะเป็นหน้าขาวของเบราว์เซอร์

**จงใจไม่แคชหน้าเว็บและ `/api`** เพราะเนื้อหาผูกกับบัญชีที่ล็อกอินอยู่
ถ้าแคชไว้แล้วสลับบัญชีหรือออกจากระบบ มีโอกาสเห็นข้อมูลของคนก่อนหน้าค้างอยู่

## การ์ดพรีวิวตอนแชร์ลิงก์

ส่งลิงก์เว็บใน LINE, Facebook หรือ Messenger แล้วจะขึ้นการ์ดพร้อมรูป
ชื่อเว็บ และคำอธิบายภาษาไทย แทนที่จะเป็นลิงก์เปล่า ๆ

รูปสร้างจาก [`src/app/opengraph-image.tsx`](src/app/opengraph-image.tsx)
ขนาด 1200x630 ใช้ไอคอนกระเป๋าตัวเดียวกับที่ติดตั้งเป็นแอป
ข้อความในรูปเป็นอักษรละตินอย่างเดียว เพราะตัวสร้างรูปมีแต่ฟอนต์ละตินติดมาให้
ถ้าใส่ภาษาไทยจะออกมาเป็นสี่เหลี่ยมเปล่า ส่วนคำอธิบายภาษาไทยอยู่ใน
`og:description` ซึ่งแอปแชตเป็นคนเรนเดอร์เอง จึงแสดงผลได้ปกติ

### ที่อยู่ของเว็บ

แอปแชตต้องการ `og:image` เป็น URL เต็ม ถ้าเป็นพาธสั้น ๆ จะดึงรูปไม่ได้

- **บน Vercel ไม่ต้องตั้งอะไร** ใช้ `VERCEL_PROJECT_PRODUCTION_URL` ที่มีให้อยู่แล้ว
- ใช้โดเมนของตัวเองให้ตั้ง `NEXT_PUBLIC_SITE_URL` (ใส่ `https://` ด้วย ไม่ต้องมี `/` ปิดท้าย)

### LINE แคชการ์ดแรงมาก

เคยส่งลิงก์ไปแล้วครั้งหนึ่ง LINE จะจำการ์ดเดิมไว้นาน แก้รูปหรือข้อความแล้ว
ส่งซ้ำก็ยังเห็นของเก่า ทดสอบด้วยการต่อพารามิเตอร์หลอกท้าย URL เช่น
`https://เว็บของคุณ/?v=2` จะได้การ์ดใหม่

## ข้อจำกัดที่ควรรู้

- **แผนเก็บเป็น JSONB ก้อนเดียวต่อผู้ใช้** (ตาราง `trip_states`) เพราะแอปอ่าน-เขียน
  ทั้งแผนพร้อมกันเสมอ ผลคือ query รายกิจกรรมด้วย SQL ไม่ได้ และถ้าเปิดแก้พร้อมกัน
  2 เครื่อง เครื่องที่บันทึกทีหลังจะทับ — ถ้าวันหลังต้องแชร์แผนหรือ query ราย
  กิจกรรม ค่อยแตกเป็นตารางย่อย
- **ครั้งแรกที่ล็อกอิน** ถ้าเครื่องนั้นมีแผนเก่าใน localStorage ระบบจะยกขึ้นบัญชีให้
  อัตโนมัติ แต่ทำครั้งเดียวตอนบัญชียังไม่มีข้อมูล
- **ค่าเข้าและระยะเวลา** ในหน้าแนะนำเที่ยวเป็นค่าประมาณสำหรับตั้งงบและจัดตาราง
  ควรตรวจสอบกับแหล่งข้อมูลทางการก่อนเดินทางจริง
- **พิกัดสถานที่แนะนำ** ดึงจาก OpenStreetMap บางจุดเป็นตำแหน่งของพื้นที่กว้าง
  (เช่นอุทยานแห่งชาติ) ไม่ใช่ทางเข้าที่แน่นอน ตอนขับจริงควรเช็กกับแอปนำทางอีกครั้ง
- **ประมาณการค่าใช้จ่าย** คิดจากราคาเฉลี่ยในไทย ใช้ตั้งงบตั้งต้นเท่านั้น
  ราคาจริงต่างกันมากตามจังหวัดและฤดูกาล
- **OSRM / Nominatim** เป็น public server มี rate limit และไม่มี SLA — หากเรียกไม่สำเร็จ
  ระบบจะเปลี่ยนไปใช้ระยะทางประมาณการ (เส้นตรง × 1.3) พร้อมแสดงป้ายเตือน
