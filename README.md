# ✈️ Travel Planner

เว็บวางแผนการท่องเที่ยว — จัดตารางกิจกรรมรายวัน คุมงบประมาณแยกหมวด เตรียมของด้วย
Checklist และดูเส้นทาง/ระยะทางบนแผนที่ ออกแบบให้ใช้บนมือถือเป็นหลัก

## เข้าสู่ระบบ

```
username: admin
password: raotworkshop
```

เปลี่ยนรหัสได้โดยตั้ง Environment Variables `AUTH_USERNAME` และ `AUTH_PASSWORD`
(ดูตัวอย่างใน `.env.example`) — ไม่ตั้งก็ใช้ค่าด้านบนได้ทันที

## ฟีเจอร์

| หน้า | ทำอะไรได้ |
| --- | --- |
| 🏠 หน้าหลัก | สรุปทริป งบคงเหลือ ความคืบหน้า Checklist และกิจกรรมถัดไป |
| 📋 แผนเที่ยว | เพิ่ม/แก้ไข/ลบกิจกรรม พร้อมเวลาเริ่ม ระยะเวลา สถานที่ และค่าใช้จ่าย + ช่องแนะนำสถานที่/กิจกรรมจากจังหวัดที่เลือก |
| 🗺️ แผนที่ | หมุดเรียงตามเวลา เส้นทางจริงตามถนน ระยะทางและเวลาเดินทางรายช่วง |
| 💰 งบประมาณ | ตั้งงบรวมและงบ 6 หมวด ดูยอดใช้ไป/คงเหลือ พร้อมสถานะสี |
| 📍 สถานที่ | Places to Visit — หมายเหตุ ความสำคัญ และสถานะไปแล้ว/ยังไม่ได้ไป |
| ✅ Checklist | รายการของที่ต้องเตรียม แบ่งกลุ่ม ติ๊กได้ มีเทมเพลตให้เติม |
| 🧭 แนะนำเที่ยว | สถานที่และกิจกรรมแนะนำ **ครบทั้ง 77 จังหวัด** กดใส่ในแผนได้ทันที |
| 📄 สรุปแผน | ดูแผนทั้งทริปในหน้าเดียว บันทึกเป็นรูป PNG หรือ PDF |
| ⚙️ ตั้งค่าทริป | เลือก 1 Day Trip หรือหลายวัน **เลือกได้หลายจังหวัดต่อทริป** จากทั้ง 77 จังหวัด ตั้งงบรวม Export/Import JSON |

## Deploy บน Vercel

1. `git init && git add -A && git commit -m "Travel Planner"`
2. push ขึ้น GitHub
3. Vercel → **Add New Project** → Import repo (ตรวจจับ Next.js ให้เอง ไม่ต้องตั้งค่าเพิ่ม)
4. (ไม่บังคับ) ตั้ง `AUTH_USERNAME` / `AUTH_PASSWORD` ใน Environment Variables
5. **Deploy**

## รันในเครื่อง (ถ้าต้องการ)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # ตรวจ TypeScript + สร้าง production build
npx eslint .
```

## Tech Stack

- **Next.js 16** (App Router, Turbopack) + React 19 + TypeScript
- **Tailwind CSS v4** — ธีมพาสเทลกำหนดใน `src/app/globals.css` (ทุกคู่สีผ่านเกณฑ์ contrast 4.5:1)
- **Leaflet + OpenStreetMap** — แผนที่ ไม่ต้องใช้ API key
- **OSRM** (ผ่าน `/api/route`) — ระยะทางจริงตามถนน
- **Nominatim** (ผ่าน `/api/geocode`) — ค้นหาชื่อสถานที่เป็นพิกัด
- **localStorage** — เก็บข้อมูลทริป ไม่มี database

## บันทึกแผนเป็นไฟล์

ในหน้า **📄 สรุปแผน** มีสองปุ่ม

- **🖼️ PNG** — วาดสรุปลง canvas เองแล้วดาวน์โหลด เหมาะกับส่งในแชท
- **📄 PDF** — เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ เลือกปลายทาง "Save as PDF"

ทั้งสองทางไม่ใช้ไลบรารีเพิ่ม จึงไม่มี dependency ใหม่ในโปรเจกต์

## ข้อจำกัดที่ควรรู้

- **ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น** เปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์แล้ว
  ข้อมูลจะหาย — ใช้ปุ่ม Export/Import JSON ในหน้าตั้งค่าเพื่อย้ายหรือสำรอง
- **ล็อกอินแบบรหัสคงที่** กันคนทั่วไปเข้าดูเท่านั้น ไม่เหมาะกับข้อมูลที่เป็นความลับ
- **ค่าเข้าและระยะเวลา** ในหน้าแนะนำเที่ยวเป็นค่าประมาณสำหรับตั้งงบและจัดตาราง
  ควรตรวจสอบกับแหล่งข้อมูลทางการก่อนเดินทางจริง
- **พิกัดสถานที่แนะนำ** ดึงจาก OpenStreetMap บางจุดเป็นตำแหน่งของพื้นที่กว้าง
  (เช่นอุทยานแห่งชาติ) ไม่ใช่ทางเข้าที่แน่นอน ตอนขับจริงควรเช็กกับแอปนำทางอีกครั้ง
- **ประมาณการค่าใช้จ่าย** คิดจากราคาเฉลี่ยในไทย ใช้ตั้งงบตั้งต้นเท่านั้น
  ราคาจริงต่างกันมากตามจังหวัดและฤดูกาล
- **OSRM / Nominatim** เป็น public server มี rate limit และไม่มี SLA — หากเรียกไม่สำเร็จ
  ระบบจะเปลี่ยนไปใช้ระยะทางประมาณการ (เส้นตรง × 1.3) พร้อมแสดงป้ายเตือน
