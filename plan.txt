## ที่มา
สเปกต้นฉบับอยู่ในไฟล์ "วันที่2" (โฟลเดอร์เดียวกัน)
เว็บวางแผนการท่องเที่ยว: จัดกิจกรรมรายวัน + คุมงบแยกหมวด + Checklist +
Places to Visit + แนะนำเที่ยวตามจังหวัด + แผนที่และระยะทาง
ล็อกอินด้วยรหัส fixed ไม่ใช้ database, deploy บน Vercel

## ข้อกำหนดจากผู้ใช้
- แผนที่/ระยะทาง : Leaflet + OpenStreetMap + OSRM (ฟรี ไม่ต้องมี API key)
- เก็บข้อมูล     : localStorage เท่านั้น + Export/Import JSON
- ข้อมูลแนะนำ    : 10 จังหวัดยอดนิยม
- การรัน         : ไม่ต้องติดตั้ง/รันอะไรเพิ่มในเครื่อง — ให้รันบน Vercel
- UI             : ภาษาไทย, Modern Minimal, mobile-first

## Tech Stack (ติดตั้งครบแล้ว ไม่ต้องลงเพิ่ม)
Next.js 16.3.3 (App Router, Turbopack) + React 19 + TypeScript
Tailwind CSS v4
leaflet 1.9 + react-leaflet 5 + @types/leaflet
ฟอนต์ Noto Sans Thai ผ่าน next/font/google

## กติกาสำคัญของระบบ
===============================================================================
- ลดจำนวนวัน  -> เตือนก่อน แล้วย้ายกิจกรรมของวันที่หายไปมาไว้วันสุดท้าย
                 (ไม่ลบทิ้งเงียบ ๆ)
- ค่าใช้จ่าย   -> spent = ผลรวม activity.cost + expense.amount ของหมวดนั้น
- สถานะสี     -> เขียว = ยังไม่เกินงบ / เหลือง = ใช้ไป >= 90% / แดง = เกินงบ
                 มาจาก getBudgetStatus() ที่เดียว ห้ามเขียนเงื่อนไขสีซ้ำ
- ลำดับกิจกรรม -> เรียงตามเวลาเริ่มเสมอ (แก้ลำดับด้วยการแก้เวลา)
- ระยะทาง     -> ขอจาก OSRM ก่อน ถ้าไม่สำเร็จใช้ haversine x 1.3 + แสดง badge
                 เตือนว่าเป็นค่าประมาณ ไม่ปล่อยให้หน้าแผนที่พัง

## Deploy บน Vercel
===============================================================================
1. git init && git add -A && git commit
2. push ขึ้น GitHub
3. Vercel -> Add New Project -> Import repo
   Framework Preset: Next.js  (ตรวจจับอัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม)
4. (ไม่บังคับ) ตั้ง Environment Variables: AUTH_USERNAME, AUTH_PASSWORD
5. Deploy

## ข้อจำกัดที่ต้องรู้
===============================================================================
- ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์เครื่องนั้น เปลี่ยนเครื่อง = ข้อมูล
  ไม่ตามไป ให้ใช้ Export/Import JSON
- ล็อกอินแบบรหัส fixed กันคนทั่วไปเข้าดูเท่านั้น ไม่เหมาะกับข้อมูลลับ
- ค่าเข้า/เวลาในข้อมูลแนะนำเป็นค่าประมาณ ควรเช็กก่อนเดินทางจริง
- OSRM/Nominatim เป็น public server มี rate limit ไม่มี SLA
